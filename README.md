# Funding Watch

Funding opportunities for the Division of Pharmacoepidemiology & Clinical Pharmacology,
Utrecht University: https://robheerdink-collab.github.io/funding-watch/

## How it works

- **Data** lives in `data/opportunities.json` (active) and `data/archive.json` (closed).
  Allowed values for every field are in `config/profile.json`.
- **The page** (`index.html`, `assets/`) reads the data in the browser. Status ("Open",
  "Closed", "Expected") and days left are calculated from today's date, so a passed deadline
  never shows as open, even if an update is late.
- **Weekly update:** every Saturday morning a scheduled Claude task clones this repository,
  follows [`UPDATE.md`](UPDATE.md), validates the data and pushes the result. GitHub Pages
  publishes it within a minute. Each run leaves a changelog in `updates/`.
- **Checks:** `scripts/build.mjs` validates every entry and blocks the push when something is
  wrong. On GitHub, the *Validate data* action repeats that check on every push, and
  *Check links* tests all call URLs every Sunday and opens an issue for broken ones.
- **Extras generated by the build:** `deadlines.ics` (calendar feed with confirmed deadlines)
  and `opportunities.csv`.

## Editing by hand

Edit `data/opportunities.json` directly on GitHub (pencil icon) and commit. Use only values
from `config/profile.json`. The *Validate data* action shows within a minute whether the file
is still valid. To change what the weekly update does, edit `UPDATE.md`; to add sources to
search, edit `sources` in `config/profile.json`.

Colleagues can suggest a missing call through the "Suggest a call" link on the page
(a GitHub issue); the weekly update processes those.

## Running locally

```bash
node scripts/build.mjs          # archive passed deadlines, validate, regenerate ics/csv/meta
node scripts/build.mjs --check  # validate only
python3 -m http.server          # then open http://localhost:8000
```
